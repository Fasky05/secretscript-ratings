# SecretScript provider ratings

Shared ratings of the free AI providers used through FreeLLMAPI in SecretScript.

- SecretScript reads `ratings.json` and lists the best providers first.
- Rating a provider in SecretScript opens a prefilled issue here. Submitting it counts the vote.
- One vote per GitHub account and provider. Voting again replaces your previous vote.
- A vote holds the stars (1-5) and the success count, failure count and median reply time measured by your own FreeLLMAPI. No keys, prompts or personal data.

Score (0-100) = 60% stars (smoothed toward 3/5 until enough votes) + 30% success rate + 10% speed.
